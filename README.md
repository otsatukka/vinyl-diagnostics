# Vinyl Diagnostics (site)

Public landing page and privacy policy for the **Vinyl Diagnostics** Android app.

- Site root: https://otsatukka.github.io/vinyl-diagnostics/
- Privacy policy: https://otsatukka.github.io/vinyl-diagnostics/privacy/

The app source lives in a separate private repository. This repo exists only to host the policy via GitHub Pages (branch `main`, path `/`).

**Note:** The privacy policy currently contains the placeholder `CONTACT_EMAIL` until a public contact address is set.
